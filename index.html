Blastival: Smash & Build Gizlilik Politikası

Son güncelleme: 2 Eylül 2026

Bu gizlilik politikası, Can tarafından CAkarsu geliştirici adıyla sunulan Blastival: Smash & Build mobil oyununda verilerin nasıl işlendiğini açıklar. Uygulamanın Android paket adı com.can.smashpro'dur.

1. Veri toplama ve paylaşma

Blastival: Smash & Build'ün mevcut sürümü kişisel veya hassas kullanıcı verisi toplamaz, geliştiriciye iletmez ve üçüncü taraflarla paylaşmaz. Oyun kullanıcı hesabı oluşturmayı veya giriş yapmayı gerektirmez.

Mevcut sürümde reklam, davranış analitiği, bulut kayıt, konum takibi veya gerçek parayla uygulama içi satın alma hizmeti kullanılmaz. Oyundaki yıldız harcamaları yalnızca oyun içinde kazanılan sanal para ile gerçekleştirilir.

2. Cihazda saklanan veriler

Mevcut level ve açılan level bilgileri, kazanılan yıldız bakiyesi, Festival Hub alanında kurulan yapılar ve açılan özel toplar yalnızca kullanıcının cihazında yerel olarak saklanır. Bu bilgiler Can veya CAkarsu sunucularına aktarılmaz.

3. Veri saklama ve silme

Blastival: Smash & Build bir kullanıcı hesabı veya sunucu tarafında kullanıcı profili oluşturmadığı için geliştiricinin sunucularında saklanan ve silinmesi istenebilecek bir kullanıcı kaydı bulunmaz. Yerel oyun verileri, uygulamanın kaldırılması veya uygulama verilerinin Android cihaz ayarlarından temizlenmesiyle silinebilir.

4. Uygulama izinleri

  • İnternet: Android paketi, kullanılan Unity altyapısı nedeniyle internet iznini içerebilir. Oyunun mevcut sürümü bu izni kişisel kullanıcı verisi toplamak veya geliştirici sunucularına iletmek için kullanmaz.

5. Çocukların gizliliği

Blastival: Smash & Build hiçbir kullanıcıdan bilerek kişisel veri toplamaz. Bu nedenle çocuklardan da bilerek kişisel veri toplanmaz veya paylaşılmaz.

6. Politika değişiklikleri

Oyuna veri işleme biçimini değiştiren analitik, reklam, hesap, bulut kayıt, gerçek parayla satın alma veya benzeri bir özellik eklenirse bu politika ve Google Play Data Safety beyanı ilgili sürüm yayımlanmadan önce güncellenecektir. Güncel politika bu sayfada yayımlanacaktır.

7. İletişim

Gizlilikle ilgili sorularınız için cankrs@gmail.com adresinden Can / CAkarsu ile iletişime geçebilirsiniz.

Blastival: Smash & Build Privacy Policy

Last updated: September 2, 2026

This Privacy Policy explains how data is handled in the Blastival: Smash & Build mobile game provided by Can under the developer name CAkarsu. The application's Android package name is com.can.smashpro.

1. Data collection and sharing

The current version of Blastival: Smash & Build does not collect personal or sensitive user data, transmit such data to the developer, or share it with third parties. The game does not require users to create an account or sign in.

The current version does not use advertising, behavioral analytics, cloud saves, location tracking, or real-money in-app purchases. Stars spent in the game are virtual currency earned only through gameplay.

2. Data stored on the device

Current and unlocked level information, earned star balance, structures built in the Festival Hub, and unlocked special balls are stored only on the user's device. This information is not transmitted to Can or CAkarsu servers.

3. Data retention and deletion

Blastival: Smash & Build does not create a user account or server-side user profile, so there is no user record stored on the developer's servers to request for deletion. Local game data can be deleted by uninstalling the application or clearing its application data through the Android device settings.

4. Application permissions

  • Internet: The Android package may include internet permission because of the Unity framework used by the application. The current version of the game does not use this permission to collect personal user data or transmit it to developer-operated servers.

5. Children's privacy

Blastival: Smash & Build does not knowingly collect personal data from any user. Therefore, it does not knowingly collect or share personal data from children.

6. Changes to this policy

If analytics, advertising, accounts, cloud saves, real-money purchases, or another feature that changes the application's data practices is added, this policy and the Google Play Data Safety declaration will be updated before that version is released. The current policy will be published on this page.

7. Contact

For privacy-related questions, contact Can / CAkarsu at cankrs@gmail.com.
